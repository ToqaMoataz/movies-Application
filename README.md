# movie_app

A new Flutter project.

## Getting Started

Developed a mobile application using Flutter that allows users to discover movies, search, browse by category, and view detailed information about each movie. Implemented Firebase Authentication following Clean Architecture principles for clean and testable authentication screens, and used Cloud Firestore for user-specific data management. Integrated external APIs to fetch movie data and utilized Hive to persist each signed-in user’s watch history and To Watch List. Applied the BLoC state management pattern to the rest of the application to ensure scalability and maintainability.
